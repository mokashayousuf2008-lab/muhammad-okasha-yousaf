# Muhammad Okasha Yousaf — Portfolio

Public scholarship, academic, leadership, volunteering, international learning, digital skills, and project portfolio.

## GitHub Pages

This is a static HTML/CSS/JavaScript website. No build step is required.

### Deploy

1. Create a new GitHub repository (for example `muhammad-okasha-yousaf.github.io`).
2. Upload **all files and folders in this directory** to the repository root.
3. Make sure `index.html` is directly in the repository root.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.
7. Wait for GitHub Pages to publish the site.

For a user site repository named `muhammad-okasha-yousaf.github.io`, the public address will be:

`https://muhammad-okasha-yousaf.github.io/`

### Important

Do not upload private documents such as CNIC/passport copies, family registration documents, scholarship application records, or documents containing sensitive identification numbers.

Keep the existing relative folder structure intact so certificate and project previews continue to work.
